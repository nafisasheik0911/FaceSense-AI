# 🤖 FaceSense AI – Facial Emotion Detection System

### AI-Based Real-Time Facial Expression Detection

FaceSense AI is a web-based Artificial Intelligence project that detects and estimates human facial expressions using a live webcam.

The system uses browser-based AI technology to analyse visible facial expressions and display the predicted expression with percentage scores.

## ✨ Features

- 📸 Real-time webcam access
- 🤖 AI-based facial expression detection
- 😊 Happy expression detection
- 😢 Sad expression detection
- 😠 Angry expression detection
- 😲 Surprise expression detection
- 😨 Fear expression detection
- 😐 Neutral expression detection
- 📊 Emotion percentage dashboard
- 💻 Responsive and modern user interface
- 🔒 Browser-side camera processing

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Face API.js
- Artificial Intelligence
- Computer Vision

## 🚀 How It Works

1. Open the FaceSense AI website.
2. Click the Start Camera button.
3. Allow camera permission.
4. Show your face in front of the camera.
5. AI analyses visible facial expressions.
6. The predicted expression and percentage scores are displayed.

## 🎯 Project Objective

The main objective of this project is to demonstrate how Artificial Intelligence and Computer Vision can be used to estimate facial expressions through a live camera.

## 🔐 Privacy and Responsible Use

Camera frames are processed within the user's browser. This demo does not intentionally upload or save camera frames.

The predictions are estimates of visible facial expressions and cannot determine a person's actual feelings or mental state. Results may be inaccurate.
